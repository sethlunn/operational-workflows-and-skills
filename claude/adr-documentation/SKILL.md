# ADR Documentation

Read [../../workflows/adr-documentation.md](../../workflows/adr-documentation.md) before starting.

Keep each ADR focused on one consequential architectural choice: its context, drivers, peer alternatives, selected option, and expected effects. Treat implementation detail and transition planning as technical-design material, not ADR content. Default to an in-session or local draft; never create or update Confluence unless the user explicitly asks.
